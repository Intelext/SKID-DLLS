Abstract: 
This talk will disclose the foundational information of exploit development in Windows. Information in the talk will include: 
  1. C Basics
  2. PEBs, PE formats
  2. Working with Windows Undocumented and Documented structures
  3. Payloads (Obfuscations, methodology, placement)
  4. Basic Injections
Additional talks and presentations will be added about more advanced techniques but this will be a foundations talk.
